Privacidade e backup.

Exporte uma cópia protegida por senha para guardar fora do navegador. Você também pode importar uma cópia anterior ou bloquear a interface deste dispositivo com um PIN.

uma cópia para guardar com segurança

Backup criptografado

O backup usa AES-GCM com chave derivada da senha via PBKDF2. Guarde o arquivo e a senha em locais seguros: não existe recuperação da senha do backup. A importação mescla registros e não apaga os atuais.

uma barreira adicional neste dispositivo

Bloqueio por PIN

Crie um PIN numérico para bloquear a interface quando sair do site.

código de recuperação · mostrado uma única vez

Guarde este código em um lugar seguro. Ele permite remover o bloqueio se esquecer o PIN. Se perder o PIN e este código, a interface não poderá ser desbloqueada por este recurso.

Importante: o PIN bloqueia a interface, mas não criptografa o banco de dados local. Para proteção real dos arquivos exportados, use o backup criptografado e uma senha que não seja o próprio PIN.
